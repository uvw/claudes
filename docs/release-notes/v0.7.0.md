## TL;DR

- **New:** `claudes session restore` puts back sessions that `session gc` moved
  to the trash.
- **Fixed:** `session gc` now forgets the move records of every session copy it
  removes.
- **Fixed:** `session search` no longer panics on a word that isn't valid UTF-8.
- **Fixed:** Printed PowerShell and shell commands stay correct for paths like
  `--%` and values with control characters.

`session gc` is no longer a one-way trip: you can now undo it, and it leaves no
stale records behind. The rest of the release fixes bugs that fuzz testing found
in search and in the commands claudes prints.

## Behavior changes

### `session restore`

`claudes session restore` lists what it can put back: ID, when it was trashed,
size, directory, and name. Add `-o json` to also see every file and the command
that moved it.

```sh
claudes session restore
claudes session restore ID
```

- `claudes session restore ID` checks every file first. It refuses, and moves
  nothing, if an original path is taken or a file has left the trash. It names
  the file and never replaces one.
- If a file can't be moved back, it stays in the trash. The report says what
  came back and what didn't. Run the command again to retry the rest.
- `--dry-run` and `--confirm` work as in other commands.
- A restored session that had been moved gets its move records back, so it still
  resumes where it moved to.
- claudes now records where each file went when `session gc`, `session mv --rm`,
  and `gc --teams` trash it. `--purge` records nothing.

### `session gc`

- When it removes a whole session (empty, trivial, gone, old, or named), it now
  drops the move records of every copy it removed. Before, it did so only for a
  single older copy. A removal that fails keeps its records.

### `session search`

- A word, `--ran`, or `--touched` that isn't valid UTF-8 now fails with an error
  instead of panicking, as a bad `-e` pattern does.
- A query no longer matches across two parts of a prompt or a tool call's
  arguments. Each part now starts its own line.

### Printed commands

- A path of exactly `--%` is now quoted as `('--%')` in PowerShell 7, so the
  rest of a printed `Set-Location` or `Remove-Item` line is no longer read as
  raw text.
- Printed resume and remove commands now drop control characters before quoting,
  so `--\x01%` no longer prints as `'--%'`.

## Platform notes

- Windows: claudes can't see where the Recycle Bin put a file, so it records
  nothing. `session restore` points you to the Recycle Bin's own Restore.
- Linux: restore also removes each file's `.trashinfo`.
- macOS: the Finder can't put `session gc` files back, so use `session restore`.
