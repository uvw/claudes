## TL;DR

- **Changed:** `claudes ls` and other commands that list sessions now query all
  your accounts at once, so they finish sooner.

This release makes listing faster when you use more than one account. Each
account used to start `claude` one after another, which added about 300 ms per
account.

## Behavior changes

### Listing sessions

claudes now lists the sessions of every account at the same time instead of one
account after another. This speeds up `ls` and every command that lists
sessions, including the polls that `restart` and `pause` run while they wait
(#20).

With two accounts, `ls` went from about 0.73 s to 0.47 s on a Mac. The output
keeps the account order, so it looks the same as before.
