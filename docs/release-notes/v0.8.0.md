## TL;DR

- **Changed:** `claudes ping TARGET MESSAGE` no longer sends the message. Use
  `-m MESSAGE`.
- **New:** `claudes ping` can target several sessions at once.
- **New:** `claudes session gc --headless` and `--junk` remove sessions with
  nothing to resume.
- **Changed:** plain `claudes session gc` now tells you what `--junk` would add.

This release makes cleanup faster and changes how `ping` takes its message. If
you call `ping` in a script, update it before you upgrade.

## Behavior changes

### `claudes ping`

`ping` now takes several sessions, and the message goes in `-m`. A message given
as a plain argument is no longer sent.

```sh
claudes ping TARGET -m "MESSAGE"
```

### `claudes session gc`

- `--headless` takes one-prompt sessions that `claude -p` or the Agent SDK ran
  and nobody opened in a terminal. It takes them only if no file changed.
  Read-only tool calls, such as `git diff`, are allowed.
- `--junk` takes every kind that holds nothing to resume: the default kinds,
  `--trivial`, and `--headless`. It leaves out `--gone`, `--older-than`, and
  `--sidecars`.
- Plain `session gc` ends its plan with what `--junk` would add:

```text
Also 5 headless session(s) (2.0M): add --junk to take them too.
```

```sh
claudes session gc --headless
claudes session gc --junk
```

`session triage` now builds its remove group the same way as `--junk`.

## Scripts that read claudes' output

- A script that runs `claudes ping TARGET MESSAGE` no longer sends MESSAGE.
  Change it to `claudes ping TARGET -m MESSAGE`.
- The plan from `session gc` can end with a new "Also ... add --junk" line. Do
  not rely on the last line being the same.

## Platform notes

- Windows: `hack/release-tokens.sh` now opens the token pages in your default
  browser from Git Bash and WSL. This script is for maintainers.

## Upgrading

1. Find every `claudes ping` call in your scripts.
2. Move the message into `-m MESSAGE`.
