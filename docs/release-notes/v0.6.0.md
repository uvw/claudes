## TL;DR

- **New:** `claudes session ls --running` and `--stopped` filter sessions by
  running state.
- **New:** Duration flags take `today`, `yesterday`, `week`, and `month`.
- **Changed:** `claudes session ls` hides the `BRANCH` column unless you pass
  `--wide`.
- **Fixed:** Tables cut long branches and names to fit the terminal, so rows no
  longer wrap.

This release makes `claudes session ls` easier to read and to narrow down. The
table now fits your terminal, and you can filter by running state and by
calendar time.

## Behavior changes

### `claudes session ls`

- `--running` keeps sessions whose `RUNNING` column says `yes`. `--stopped`
  keeps the rest. Both are long-only, and you cannot use them together.
- The filters apply after `-i`, `-l`, and targets, and before `--sort`.
- The default table shows `ID`, `RUNNING`, `ACTIVE`, `SIZE`, `DIR`, and `NAME`.
  Add the branch back with `--wide`.

```sh
claudes session ls --running
claudes session ls --stopped -l week
claudes session ls --wide
```

### Calendar words for durations

Every duration flag takes `today`, `yesterday`, `week`, or `month`, in any
letter case. This covers `-l`/`--since` on `session ls`, `session du`,
`session search`, and `session triage`. It also covers `--older-than` on `gc`
and `session gc`.

- `today` starts at local midnight today. `yesterday` starts at midnight
  yesterday and includes today.
- `week` starts on this week's Monday. `month` starts on the 1st of this month.
- `claudes session gc --older-than month` removes sessions last active before
  this month began.

### Table widths

Every table with a `NAME` column now fits the terminal, not only `session ls`.
When a line is too wide, claudes cuts columns in this order, each down to a
minimum width:

1. The last column, such as `FIRST PROMPT` or `DOING`.
2. `DIR`.
3. `NAME`.
4. `BRANCH`.

Branches are cut to 24 columns, keeping the first part and the end of the name:

```text
feat/ledger-rounding-for-every-currency  ->  feat/…for-every-currency
```

With `output.dirs: full`, `DIR` is never cut, so `NAME` and then `BRANCH` give
way. Output that is not a terminal keeps its old widths.

## Scripts that read claudes' output

- `claudes session ls` no longer prints a `BRANCH` column by default. Pass
  `--wide` if your script reads it.
- `-o json` and `-o yaml` are unchanged and still carry the full branch.
- Cut text in tables ends in `…`. Read JSON or YAML for full values.
