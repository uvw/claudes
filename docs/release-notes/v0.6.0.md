## TL;DR

- **New:** `claudes session ls --running` and `--stopped` filter sessions by
  running state.
- **New:** Duration flags accept `today`, `yesterday`, `week`, and `month`.
- **Changed:** `claudes session ls` hides the `BRANCH` column unless you pass
  `--wide`.
- **Fixed:** Tables cut long branches and names to fit the terminal instead of
  wrapping.

This release makes `claudes session ls` easier to read and filter. The default
table is narrower, and you can pick sessions by running state and by calendar
spans such as `week`.

## Behavior changes

### `session ls`

- `--running` keeps sessions whose `RUNNING` column says `yes`. `--stopped`
  keeps the rest. Both are long-only, and you cannot pass both.
- The default table shows ID, RUNNING, ACTIVE, SIZE, DIR, and NAME. Add `--wide`
  to get `BRANCH` back between SIZE and DIR.
- `-o json` and `-o yaml` are unchanged and still carry the whole branch.

```sh
claudes session ls --running
claudes session ls --stopped --wide
```

### Calendar words for durations

Every duration flag now accepts `today`, `yesterday`, `week`, and `month`, in
any letter case. Each counts from a local midnight to now:

- `today`: the midnight that started today.
- `yesterday`: the midnight that started yesterday, so it includes today.
- `week`: the Monday of this week.
- `month`: the 1st of this month.

This works on `-l`/`--since` for `session ls`, `session du`, `session search`,
and `session triage`. It also works on `--older-than` for `gc` and `session gc`.

```sh
claudes session ls --since today
claudes session gc --older-than month
```

### Table widths

- Long branches are cut to 24 columns. `feat/ledger-rounding-for-every-currency`
  shows as `feat/…for-every-currency`.
- On a terminal, tables shrink `DIR`, then `NAME`, then `BRANCH` so rows no
  longer wrap. This covers every table with a `NAME` column, including `ls`,
  `where`, `session du`, `session search`, and `session triage`.
- With `output.dirs: full`, `DIR` is never cut. `NAME` and then `BRANCH` are cut
  instead.
- Off a terminal, nothing changes.

## Scripts that read claudes' output

- `session ls` no longer prints a `BRANCH` column by default. If a script parses
  the table, pass `--wide`, or read the `branch` field with `-o json`.
- Tables on a terminal may now show shortened branches and names. Use `-o json`
  or `-o yaml` for full values.
