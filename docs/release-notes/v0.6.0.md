## TL;DR

- **New:** `claudes session ls` takes `--running` and `--stopped` to filter by
  running state.
- **New:** Duration flags accept `today`, `yesterday`, `week`, and `month`.
- **Changed:** `claudes session ls` shows the `BRANCH` column only with
  `--wide`.
- **Fixed:** Tables cut long branches and names to fit your terminal instead of
  wrapping.

This release makes `session ls` easier to read and filter. The default table is
narrower, and long rows no longer wrap.

## Behavior changes

### `session ls`

Filter by running state. Passing both flags is an error.

```sh
claudes session ls --running
claudes session ls --stopped
```

The filters apply after `-i`, `-l`, and targets, and before `--sort`.

The default table no longer has a `BRANCH` column. Add it back with `--wide`:

```sh
claudes session ls --wide
```

### Duration flags

`-l`/`--since` on `session ls`, `session du`, `session search`, and
`session triage` accept calendar words. So does `--older-than` on `gc` and
`session gc`. Case does not matter.

- `today`: since local midnight.
- `yesterday`: since midnight yesterday, which includes today.
- `week`: since Monday of this week.
- `month`: since the 1st of this month.

```sh
claudes session gc --older-than month
```

### Table widths

On a terminal, tables now cut columns to fit instead of wrapping. This covers
every table with a `NAME` column, such as `ls`, `where`, `session du`,
`session search`, and `session triage`. The cut order is `DIR`, then `NAME`,
then `BRANCH`. Branches are cut to 24 columns and keep the start and end:

```text
feat/ledger-rounding-for-every-currency  ->  feat/…for-every-currency
```

With `output.dirs: full`, `DIR` is never cut, so `NAME` and `BRANCH` are cut
instead. Output off a terminal keeps its old widths.

## Scripts that read claudes' output

- `session ls` no longer prints a `BRANCH` column by default. If a script reads
  it from the table, add `--wide`.
- `-o json` and `-o yaml` are unchanged and still carry the full branch.
